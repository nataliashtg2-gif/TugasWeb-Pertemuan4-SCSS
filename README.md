# TugasWeb-Pertemuan4-SCSS

Konversi CSS dari Tugas Pertemuan 2 menjadi SCSS dengan struktur modular 7-1 pattern.

## Requirements
- Konversi CSS existing ke SCSS
- Variables untuk colors & spacing
- Nesting maksimal 3 level
- Minimal 3 mixins reusable
- Struktur 7-1 pattern
- Menggunakan @use
- Menggunakan @each
- Compile dengan Vite / Dart Sass

## Menjalankan
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```
